## The one-paragraph version

Imagine someone wrote a brilliant recipe book, and a machine is being built to photocopy that
book into a website. The recipe book is finished and excellent. The photocopier is **about two
thirds built**. It runs, it makes 52 pages, and a built-in inspector says "all good" — but I
found **five real problems the inspector doesn't catch**, including one where the machine
quietly loses 35 of the 47 web links it is supposed to check. The copy is safe and untouched.
The look is done and inside its budget. The parts that make the site *feel* like an app —
remembering your progress, copy buttons, search, offline reading — have **not been started**.

---

## 1. What is this thing, really? (plain language first)

A complete, **free, 24-week course** that takes someone in Nigeria from knowing nothing about
HR (the people-team in a company) to being ready to apply for their first job as a recruiter
or HR assistant.

It started life as **five documents** — like five long Word files. Five documents are great for
studying but bad for two everyday questions:

1. "What am I supposed to do tonight?"
2. "Did I already finish this one?"

So the job now is: **turn the five documents into a website** — without changing a single
sentence of the writing.

### The four boxes in the workshop

| Box | What's in it | A 12-year-old version |
|---|---|---|
| **`content/`** | The five documents, in markdown | The **master recipe book**. Never photocopy over it. |
| **`design-system/`** | Colours, sizes, fonts, shadows | A **Lego box** with only certain bricks. You may not paint your own. |
| **`tools/`, `scripts/`** | The generator + inspectors | The **photocopier** and the **spell-checker**. |
| **`_site/`** | The finished website | The **stack of printed pages**. Throwaway — you can always reprint. |

### The golden rules (from `site-plan/00-CONTEXT.md`)

1. **One master copy.** The website is *made from* the documents. Nobody retypes sentences into
   web pages. (This is the "no content fork" rule.)
2. **The Lego box owns the look.** No inventing colours, sizes or shadows. If a value isn't in
   the box, you write a `TODO` and ask.
3. **No accounts, no spying.** Progress is saved in *your own browser*, on *your own phone*,
   and never travels anywhere. A website about job-hunting should not be collecting job-hunters'
   data. That rule is deliberate and it is being kept.
4. **Every fact carries a date.** Pages print "Checked 20 October 2026" so a reader knows how
   old the advice is.
5. **Don't sound certain when the source isn't.** If the original says a fee is "roughly ₦20k–₦70k",
   the website must not say "₦45k".

## 2. How the machine works

```
content/docs/src/doc1..5.md   ──►  scripts/docx_render.py  ──►  parsed blocks
content/HR_Library_Overview.md       (the parser — shared with the       │
                                      .docx writer, deliberately)        │
                                                                        ▼
design-system/artifacts/wakeout.css ──►  tools/sitegen/sitegen.py  ──►  _site/  (52 pages)
site/static/site.css                      (the photocopier)                 │
                                                                            ▼
                                          tools/sitegen/audit.py  ──►  13 checks
                                          (the inspector)
```

Two commands. That's the whole build:

```bash
python3 tools/sitegen/sitegen.py    # print the pages
python3 tools/sitegen/audit.py      # inspect the pages
```

## 4. The roadmap — six levels, and we're on Level 1

Think of it like a game with six levels. Each level has an "you may only leave this level when…"
test.

| Level | Name | Status |
|---|---|---|
| **0** | Get the inputs, check the ground truth | 🟡 Mostly done — 1 of 3 steps left undone |
| **1** | Build the machine and the pages | 🟡 ~85% done, but with holes (see §5) |
| **2** | Progress, copy buttons, filters | ⬜ Not started |
| **3** | Search engines, offline, polish | ⬜ Not started |
| **4** | Pre-launch testing on real phones | ⬜ Not started |
| **5** | Launch + the maintenance promise | ⬜ Not started |

### What's left on each level

**Level 0 — the unfinished bit:** step **0.2**, re-checking all **47 web links**. This is the
single most important unfinished job, because the whole promise of the site is "these free
courses are really free, and we checked." If a course quietly started charging, the site would
be confidently wrong. The links were last checked on **20 October 2026** — yesterday.

**Level 1 — the holes:** the five bugs in §5.

**Level 2 — the fun part:** progress ticks that survive a rebuild, copy buttons, filters, and a
glossary you can search as you type. Roughly six small jobs.

**Level 3 — being findable and offline:** sitemap, search-engine snippets, and a "pack the site
into your phone so it works with no data" feature. This is the feature that matters most for
someone on prepaid data.

**Level 4 — real-world testing:** Lighthouse scores, keyboard-only run, printing an actual A4
page, loading on a real Android phone over 3G.

**Level 5 — launch:** put it online, then the only repeating job: **every three months, re-run
the link check.** If a course's terms changed, edit the document, reprint, and the date stamp
updates itself. Nobody ever edits the website by hand, so there's nothing to forget.

## 5. The five real problems I found

These are things the inspector says nothing about. I found them by reading the code and testing.

---

### 🔴 Problem 1 — The link page silently loses 35 of 47 links

**What should happen:** `/check/` lists every one of the **47** external web addresses in the
documents, with its status.

**What actually happens:** it lists **12**. All 12 are from Alison. The other 35 — Saylor,
the Open University, CIPD, the Nigerian Labour Act PDF, CIPM, PenCom, Jobberman, the National
Industrial Court, and so on — **are not on the page at all.**

**Why:** the collector only looks for links written the *markdown* way, `[words](https://…)`.
There are exactly **12** of those in the whole library. The other **35** are written as *bare*
addresses, like `Link: https://saylor.org/…`. The machine happily turns those into clickable
links on the page — it just never counts them.

**How I proved it:** I swapped in a collector that looks for both kinds. It found **34**. Adding
the 12 markdown ones on top gives **47** — exactly the number the spec says.

**Why it matters:** a page that says "we checked every link" but lists a quarter of them is worse
than no page, because it makes people trust it too much. This is the kind of thing that quietly
damages the whole project's credibility.

**Fix:** one small change in `tools/sitegen/sitegen.py` (function `external_urls`) — search with
both patterns. Roughly a 3-line change.

---

### 🔴 Problem 2 — The machine only runs on a very new Python

**What happens on this machine:**

```
File "tools/sitegen/sitegen.py", line 273
SyntaxError: f-string expression part cannot include a backslash
```

**Why:** one line packs escaped quotes inside an f-string. That only became legal in **Python
3.12** (a rule change called PEP 701). This machine has **Python 3.11** — so the build is dead
on arrival.

**Why it matters:** the previous session used Python 3.14 and never noticed. Anyone — the owner,
a helper, a hosting service, a robot inspector — on Python 3.11 or older gets an instant crash
with no explanation. **The minimum version is nowhere written down.** There is no
`requirements.txt`, no `pyproject.toml`, no `setup.py`, and no `Makefile`, even though the
handoff README tells people to run `make check`, which does not exist.

**How I proved it:** I copied the repo to a scratch folder, rewrote that one line without escaped
quotes, and everything ran perfectly — 52 pages, 13/13 checks. So it's genuinely just this.

**Fix:** rewrite the one line (5 minutes) **and** write down the rule "needs Python 3.12+."
Two small jobs.

---

### 🟠 Problem 3 — The "copy this" page is missing four of its five things

**What the spec asks for** (requirement R5): five copyable blocks — CV bullet rewrites, the
90-word application note, follow-up messages, the 12-question intake template, and the
reference-check script.

**What exists:** one page holding only **SUPPORT C — the follow-up messages**. The other four
are sitting on the main "Getting the job" page as ordinary paragraphs.

**Why it matters:** there are **zero buttons on the entire website** (I counted). So "copyable"
currently means "you can select it with your finger." On a phone, copying a long block of text
is genuinely annoying — that's the whole reason this feature exists.

**Note:** this is the least scary of the five, because the copy buttons were always planned for
Level 2. The real finding is that the page is **narrower than the spec says**, and nobody had
written that down.

---

### 🟠 Problem 4 — The bookkeeping files aren't honest about what's unverified

`STATUS.md` is the "where we are" file, and it deserves credit: it has a section literally
called **"Not verified, and why"**, which is exactly the right instinct and better than most
projects manage. But three things are missing from it:

1. **The 12-of-47 link problem** is not mentioned. It only says the sweep hasn't run — not that
   the page is missing three quarters of the links.
2. **The "proven numbers" are already slightly stale.** It says the biggest page is 27,233 bytes
   and the CSS is 4,579 bytes gzipped. I measured **27,426** and **~5,000**. Tiny drift, but the
   section is headed "Numbers that are proven (rerun the command, don't trust the line)" — and
   the numbers drifted because someone trusted the line.
3. **The `.docx` regression check can't run here.** It needs a Python library called
   `python-docx`, which isn't installed and isn't declared anywhere. `STATUS.md` mentions it in
   "session traps," but a trap is not a dependency list.

**Also worth knowing:** the requirement R1 says the machine should *fail the build* if it ever
prints a sentence that didn't come from the documents. I grepped for that guard — **it isn't
there.** Today it's enforced by a human running `git status` and eyeballing it. That has held so
far (`content/` is spotlessly clean), but it isn't automated.

---

### 🟡 Problem 5 — Small things worth knowing

- **Two broken Lego bricks.** The design system declares `--wk-muted` twice, and the second time
  it says "`--wk-muted` means `--wk-muted`" — which means nothing at all. Same for
  `--wk-muted-foreground`. Any page using them renders them as invisible. The site already works
  around this, but the fix belongs upstream in the owner's design system, not here. There's a
  second oddity: `--wk-tilt-dramatic` is set to `±12deg`, which isn't valid CSS.
- **11 KB of font files are packed but never used.** The site ships four font files. Because they
  aren't tagged by character range, a browser downloads the two main ones and never touches the
  two "-ext" ones. Harmless, but 11 KB of every deploy is dead weight.
- **Fonts are loaded by absolute path** (`/fonts/…`). Fine if the site lives at the top of a
  domain; breaks if it ever lives in a subfolder.
- **The README says "the site it generates is 32 routes."** It generates **52**.
- **The home page still says "Six files, one plan"**, but only five documents are on offer.
  Already flagged to the owner as a wording decision.

## 7. The honest "we don't know yet" list

Real engineering is mostly knowing what you haven't checked. This project is **unusually good**
at admitting this — `STATUS.md` keeps a running list. Here's the current one:

- **Nobody has seen it.** The design was checked by reading the computed styles and the page
  structure, not by looking at it. The preview window wouldn't draw. So "it looks right" is
  **not** a claim anyone can make yet.
- **Nobody has printed it.** The print stylesheet is written, but no PDF has been produced. The
  "one-page law card that fits on a single A4 sheet" is **designed** but not **proven**.
- **No speed test, no phone test, no keyboard-only test.** All Level 4 work.
- **No link has been re-checked since 20 October 2026** — yesterday.
- **The font licence file is missing.** The fonts are free to use (SIL OFL 1.1), but that licence
  says you must ship its text along with them. Currently nothing in the repo does. **This must be
  fixed before the site goes public.**
- **The design system's own notes say:** if this ships publicly, rename the system and replace
  the copy — it was reverse-engineered from a live brand. The colours and measurements are facts
  and are fine; the *name* is not ours to use.
