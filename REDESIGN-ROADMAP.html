Redesign: where we are

The site was painted with a token set taken from an unrelated third-party site, which is why it was green with rounded pills while its sister site was cream and square. This is the work of moving it onto one shared system.

The stages

1 · Deconstruct the Nature Photography site done

Read its source rather than its rendered page, so every value is measured instead of guessed: 27,771 characters of CSS, 143 classes, 27 custom properties.

  • DESIGN.md — principles, the page spine, the component inventory, content conventions
  • STYLE-GUIDE.md — palette, type scale, fluid spacing, borders, shadows, motion

2 · Build the shared token system done

One source both sites can draw from, replacing the Wakeout set.

  • tokens/fieldnotes.tokens.json → artifacts/fieldnotes.css, 107 tokens
  • The Wakeout token file, its five unbuilt artifacts and three extraction tools are gone — a dead stylesheet beside a live one is how an old system comes back
  • Its evidence stays in ref/ so the provenance is on the record

commit ac63b41

3 · The visual overhaul done

The language moved, not just the palette.

  • Square corners — the reference contains one border-radius in 27,771 characters; this keeps a 2px softening on the smallest controls only
  • Hard shadows, no blur — cards rest at 6px and lift −3px into 10px of pink on hover
  • Monospace chrome — headings, labels, buttons, stamps, table heads; running copy opts into the reading face
  • The hero kicker is a chip rather than loose uppercase

commit ac63b41

4 · Drop the webfonts done · your call

Fredoka and Space Grotesk were 68% of a cold first visit. The cold-visit budget dropped from 100 KB to 40 KB as a consequence — the old figure was measuring nothing against 22 KB of real weight, and 40 KB is below what the fonts alone cost, so the budget is now what stops them returning.

commit ac63b41

5 · The live /style-guide route done

Every component rendered from the tokens it ships with, so a component and the token behind it cannot drift.

  • 23 colour swatches, each with the contrast pair it is really used in
  • 11 type sizes in both faces · 11 spacing steps · 4 border widths · 6 shadows
  • 12 components, built with the classes the pages actually use
  • No inline styles: the per-token classes are generated from the token file at build time, so the repo's ban stays absolute

6 · Look at it needs you

No browser has run on the redesign. The gate proves the rules are satisfied, not that the page looks right. Every value is tokenised and measured, but nobody has seen square cards, the pink hover lift or monospace headings rendered. The preview is live — this is the one thing the gate cannot do for us.

7 · The four checks that need a browser blocked

  • Lighthouse mobile on the four heaviest routes
  • The 3G cold load
  • Android print
  • The service worker: install, go offline, reload ten times

Each needs a real browser or a real deploy. None can be faked from here.

8 · A shared home for the tokens later · your call

The docs live in the HR repo for now, as you chose. When there is a shared home they lift out unchanged — nothing in them refers to HR specifically.

Decisions made along the way

Not copied: the rendering model

The reference builds all 25 cards from JavaScript, so its catalogue is empty with JS off, and it carries a second renderer to patch that. This site's words are in the HTML, proven by the JS-off crawl. Taking the visual system while leaving the rendering model alone was deliberate.

Not copied: the invalid ARIA

The reference labels its hero stats with aria-label on a plain div, which assistive technology does not honour and which is invalid. The stats are a real list here, so the grouping is announced by the list itself. The look is the reference's; the defect is not.

Found by mutation testing

After moving the contrast check over, a planted fault in a sticker variant slipped straight through: the check measured the base class against six grounds someone had listed by hand. Variants are now read out of the stylesheet and measured individually — 25 pairs became 31, and the same fault now fails at 2.95:1.

Still open on Vercel

The dashboard's build-command override may still be set. It takes precedence over vercel.json, so it is worth clearing — otherwise the repo is not the only source of truth for how the site builds.
